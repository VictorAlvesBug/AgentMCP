# Para rodar um comando python diretamente pelo terminal, utilize:

```py
python -c "from message_agent import config; print(config.MCP_SERVERS.keys())"
```

# Para executar uma função específica, utilize:

```py
python -m message_agent.teste_hub
# -m: Roda o arquivo como módulo
```
